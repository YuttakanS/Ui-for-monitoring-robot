1. เตรียม

  1. ใน firmware/robot/robot.ino ตั้ง ESTIMATE_Z = false แล้ว upload (หน้านี้ส่งคำสั่ง MODE 3 ให้บอร์ดส่งบรรทัด RSS เองตอนเชื่อมต่อ ไม่ต้องแก้ mode)
  2. เลือก LED ที่ติดอยู่จริงด้านล่าง แล้วปิดหน้า Position Monitor ก่อน (เปิดพอร์ตพร้อมกันไม่ได้) กด เชื่อมต่อ Serial หน้านี้จะเปิด/ปิด LED ในบอร์ดตามที่เลือกให้เอง หรือต่อคอมเข้า WiFi ของหุ่นแล้วกด เชื่อมต่อ WiFi (ไม่ต้องปิดหน้า Position Monitor)
  3. วางหุ่นบนพื้น หันมุม θ = 0°: photodiode ที่ต่อขา GP28 หันไปทาง +X (ทางขวาของแผนที่)
  4. ปิดไฟห้องหรือคุมแสงให้เหมือนกันทุกจุด อย่าแตะหุ่นตอนเก็บค่า
  5. เก็บครบทุกจุดที่แนะนำ แล้ว copy บรรทัด PtxGamma ในข้อ 4 ไปใส่ robot.ino

4. ผล PtxGamma, PD_GAIN, RSS_OFFSET

LEDγ ใหม่γ เดิมเปลี่ยนค่าที่ใช้คลาด (rms) PD0PD1PD2ค่าจริงใน Demo
—

คำนวณ γ ของแต่ละ LED พร้อมกับ PD_GAIN (ความไวของ PD1, PD2 เทียบกับ PD0) และ RSS_OFFSET (ค่าคงที่ที่บวกเพิ่ม เช่นแสงสะท้อน) ให้ copy ทั้ง 3 บรรทัดไปแทนใน robot.ino และแก้ CURRENT_GAMMA, PD_GAIN, RSS_OFFSET ใน calib-model.js ให้ตรงกัน (npm test ตรวจให้) PD0–PD2 = photodiode แต่ละตัวอ่านสูง (+) หรือต่ำ (−) กว่าแบบจำลอง (ที่รวม PD_GAIN แล้ว) โดยเฉลี่ย ถ้ายังเกิน ±5% ให้จดไว้ สีแดง = คลาดเกิน 10% หรือ photodiode เอียงเกิน 5% หรือหุ่นแกว่งเกิน 5% ระหว่างเก็บ LED ที่ไม่ได้คำนวณใช้ค่าเดิม
